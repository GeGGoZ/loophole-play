# LOOPHOLE — play in your browser

**Draw loops around the horde. Swallow everything.**

Play: https://geggoz.github.io/loophole-play/

- **Desktop:** move the mouse to steer, click to dash, Esc to pause.
- **Phone / tablet:** drag anywhere to steer, tap **DASH**, **II** to pause. Works in portrait and landscape.
- **iPhone / iPad:** open the link in Safari → Share → **Add to Home Screen** for a full-screen app.
- Touch controls forced on (e.g. iPad with a keyboard): https://geggoz.github.io/loophole-play/mobile.html

This repo only contains the built game.
